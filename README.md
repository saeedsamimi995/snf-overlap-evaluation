# Overlapping community detection on fused patient-similarity graphs

Locked multi-cohort evaluation of hard and soft community detection on breast-cancer expression graphs. The lead is a pre-specified rule. Classical BIGCLAM is an a priori baseline and cannot become the lead, even when its LumA odds ratio, IntClust enrichment, or simulation correlation is higher.

Discovery is GSE96058/SCAN-B (n=3,273). Validation is TCGA-BRCA (n=1,093). External survival is METABRIC (n=1,980). GSE25066 (n=508) was added later as a pre-stated treatment-response cohort and is null. The manuscript is `manuscript/manuscript.tex`. Locked hyperparameters are in `manuscript/SUPPLEMENTARY_METHODS.md`. The bake-off, related-work notes, and rebuild commands are in `docs/STUDY_NOTES.md`. The ceiling decision is `results/ceiling/decision_note.md`.

## Install

```bash
conda env create -f environment.yml
conda activate snf-dual-output
```

`pip install -r requirements.txt` is the alternative. Expression matrices and GEO archives stay in `data/` and are not part of the git tree. Cached `.npy` graphs and memberships are regenerated by the scripts below and are gitignored.

## Run the locked study

From the project root:

```bash
python run_snf_overlap_sota.py --harmonized-dir data/harmonized --results-dir results/snf_overlap_sota --reuse-bigclam-dir results/snf_bigclam
python scripts/rank_overlap_sota.py
python -m scripts.run_ceiling_experiments
python -m src.analysis.gse25066_response
```

The GSE25066 command does not retune K, k, mixed ratios, or the gene list. Its pre-stated tests are null, so there is no treatment-resistance claim.

Rebuild the Word manuscript after figure or table edits:

```bash
python manuscript/revise_figures_and_tables.py
python manuscript/export_figures.py
python manuscript/build_docx.py
```

`main.py` still trains an MLP and an SVM on hard BIGCLAM labels. That accuracy is not a study result.
